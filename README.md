# Traffic Light – setInterval Practice

A simple JavaScript project that simulates a traffic light system.  

---

## Features
- Automatic light cycle: **Red → Yellow → Green → Red**
- Timing controlled with **setInterval()**
- Clean and simple UI using HTML & CSS
- Exercise for understanding JavaScript timers

---

## Technologies Used
- **HTML5**
- **CSS3**
_ **React**
- **JavaScript (ES6+)**


## How to Run This Project

```bash
# Clone the repository
git clone https://github.com/fabioesilveira/Light.git

# Enter the project folder
cd Light

# Install dependencies
npm install

# Start the development server
npm run dev
